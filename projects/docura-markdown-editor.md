# Docura - The Open Source Typora Alternative

*March 2024 · Rust · Tauri · Cross-platform*

## Overview

Docura is an Open Source Alternative for Typora for Windows, macOS and Linux. Docura is a simple, elegant, and powerful markdown editor that provides a seamless writing experience with real-time preview and extensive customization options. It supports various markdown features, including tables, code blocks, images, and links, making it ideal for writers, developers, and content creators.

## Key Features

### Real-time Preview
See your markdown rendered as you type, providing instant feedback and a seamless writing experience.

### Syntax Highlighting
Supports syntax highlighting for code blocks in various programming languages, making it perfect for developers and technical writers.

### Customizable Themes
Choose from a variety of themes or create your own to personalize your writing environment and reduce eye strain.

### Distraction-free Mode
Focus on your writing with a clean and minimal interface that eliminates distractions and promotes productivity.

### Export Options
Export your documents to HTML, PDF, and other formats for sharing and publishing.

### Cross-platform Support
Available on Windows, macOS, and Linux, ensuring consistent experience across different operating systems.

### Open Source
Free to use and modify under the APL-2.0 License, with active community development and contributions.

### Lightweight Performance
Fast and responsive, even with large documents, thanks to the efficient Rust and Tauri architecture.

### File Organization
Manage your markdown files with ease using the built-in file explorer and project management features.

### Keyboard Shortcuts
Boost your productivity with customizable keyboard shortcuts for common operations.

## Technical Architecture

### Built with Modern Technologies
- **Tauri Framework**: Provides secure, lightweight desktop application development
- **Rust Backend**: Ensures high performance, memory safety, and reliability
- **Web Frontend**: Modern, responsive user interface using web technologies

### Security and Performance
The Rust and Tauri combination provides:
- Enhanced security through Rust's memory safety
- Improved performance with native code execution
- Smaller application size compared to Electron-based alternatives
- Better resource management and efficiency
