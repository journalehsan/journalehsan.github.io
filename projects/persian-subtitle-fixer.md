# Persian Subtitle Fixer

*November 2023 · C++ · Qt · Cross-platform*

## Overview

A simple tool to fix common issues in Persian subtitles, such as encoding problems, incorrect character mappings, and formatting errors. It helps ensure that Persian subtitles display correctly across different media players and devices.

## The Problem

Persian subtitles often suffer from:
- **Encoding Issues**: Wrong character encoding causing garbled text
- **Character Mapping Problems**: Incorrect Unicode mappings specific to Persian script
- **Formatting Errors**: Inconsistent spacing, punctuation, and line breaks
- **Compatibility Issues**: Subtitles not displaying correctly across different media players

## Key Features

### Encoding Correction
Fixes common encoding issues in Persian subtitles, ensuring proper character display across all platforms and media players.

### Character Mapping
Corrects incorrect character mappings specific to Persian script, resolving Unicode-related display problems.

### Formatting Adjustments
Cleans up formatting errors to improve subtitle readability and consistency.

### Batch Processing
Allows users to fix multiple subtitle files at once, saving time when working with large collections.

### User-friendly Interface
Simple and intuitive UI designed for ease of use, even for non-technical users.

### Drag-and-Drop Support
Easily add subtitle files by dragging them into the application window for quick processing.

### Preview Feature
View changes before saving the fixed subtitles, allowing you to verify corrections.

### Lightweight Performance
Minimal resource usage for quick processing, even with large subtitle files.
